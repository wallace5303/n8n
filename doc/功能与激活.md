## 社区版激活机制

### 1. 注册入口
在 [license.controller.ts](file:///Users/gsx/www/gofile/src/common/n8n/packages/cli/src/license/license.controller.ts#L43) 中有一个 API 端点：
```typescript
@Post('/enterprise/community-registered')
async registerCommunityEdition(...)
```

### 2. 注册流程
在 [license.service.ts](file:///Users/gsx/www/gofile/src/common/n8n/packages/cli/src/license/license.service.ts#L69-L95) 中的 `registerCommunityEdition` 方法：
- 向 `https://enterprise.n8n.io/community-registered` 发送请求
- 传入参数：`email`, `instanceId`, `instanceUrl`, `licenseType: 'community-registered'`
- 服务端返回一个 `licenseKey`
- 触发事件 `license-community-plus-registered`

### 3. 激活后解锁的功能
社区版注册后，服务端会下发一个 **licenseKey**。这个 licenseKey 需要通过 [activateLicense](file:///Users/gsx/www/gofile/src/common/n8n/packages/cli/src/license/license.service.ts#L113) 方法激活。

激活后，License Manager 会根据证书中的授权信息决定哪些功能可用。

### 4. 功能控制逻辑
在 [license.ts](file:///Users/gsx/www/gofile/src/common/n8n/packages/cli/src/license.ts#L254-L280) 中的 `isLicensed` 方法控制功能开关：

```typescript
isLicensed(feature: BooleanLicenseFeature) {
    const enabledFeatures = this.globalConfig.license.features;
    const disabledFeatures = this.globalConfig.license.featuresDisabled;

    // 检查是否在禁用列表中
    if (disabledFeatures) { ... }

    // 如果开启列表为 '*'，表示开启所有功能
    if (enabledFeatures === '*') {
        return true;
    }

    // 检查是否在开启列表中
    if (enabledFeatures) { ... }

    // 默认行为：使用 LicenseManager 检查
    return this.manager?.hasFeatureEnabled(feature) ?? false;
}
```

### 5. 环境变量强制开启功能
可以通过环境变量 **强制开启或关闭** 任何功能，无需激活：

| 环境变量 | 说明 |
| --- | --- |
| `N8N_LICENSE_FEATURES` | 逗号分隔的开启功能列表，`*` 表示全部开启 |
| `N8N_LICENSE_FEATURES_DISABLED` | 逗号分隔的禁用功能列表，优先级最高 |

## 结论

**`project-personal-menu-item` 菜单页由以下任一功能解锁：**

| 功能 | License 标识 | 类型 |
|------|-------------|------|
| **团队项目（Team Projects）** | `quota:maxTeamProjects` | Quota（配额） |
| **文件夹（Folders）** | `feat:folders` | Feature（功能开关） |

在您的代码中，[license.ts](file:///Users/gsx/www/gofile/src/common/n8n/packages/cli/src/license.ts#L267) 已经做了修改，通过 `N8N_LICENSE_FEATURES=*` 环境变量可以强制开启所有功能。因此当社区版使用密钥激活后：

1. `feat:folders` 被启用 → `isFoldersFeatureEnabled = true`
2. 或者 `quota:maxTeamProjects` 被设置为非 0 → `isTeamProjectFeatureEnabled = true`

**任一条件满足，`project-personal-menu-item` 就会显示。**

实际上，这个菜单项代表的是**个人项目空间（Personal Project）**，它是 Projects 功能体系的一部分。当团队项目或文件夹功能被启用时，系统会将用户的工作流和凭证组织到"个人项目"中，并在左侧导航栏显示这个入口。
